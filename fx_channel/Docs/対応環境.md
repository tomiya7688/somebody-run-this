# 対応環境

fx_channel の正式な配布ターゲットです。

> 現在は実装初期段階のため、ここに書かれている環境は **正式対応を目指すビルドターゲット** です。
> Releaseを「対応済み」と扱うのは、そのターゲット用成果物のビルドと起動確認が通った後にします。

## ユーザー用アプリ

| OS | アーキテクチャ | 最低環境 | 配布形式 |
|---|---|---|---|
| Windows | x64 / x86_64 | Windows 10 以上 | ZIP内の実行ファイル |
| Android | arm64-v8a | Android 9.0 / API 28 以上 | APK |

### Windows

- 32bit x86は対象外
- ARM版Windowsは当面対象外
- Windows 10未満は対象外

### Android

- arm64-v8aのみを正式対象にする
- Android 9.0 / API 28以上
- x86/x86_64 Android Emulator向けは開発用に作ることはあっても正式配布対象にはしない
- 32bit ARMは正式対象外

## 運営用アプリ

運営用アプリはユーザー用とは別配布です。

初期の正式ターゲット：

- Windows x64
- Linux x64

運営用アプリをAndroidへ載せることは標準方針にしません。

## サーバー

サーバーはできるだけ一般的なVPS・専用サーバー・クラウドVMへ、そのまま配置して動かせることを目標にします。

正式な配布ターゲット：

| 配布物 | 主な用途 |
|---|---|
| Linux x64 | Ubuntu Server / Debian / 一般的なx64 Linux VPS |
| Linux arm64 | ARM64のUbuntu Server / Debian / ARMクラウドVM |
| Windows x64 | Windows Server / Windows上での小規模セルフホスト |

Linuxはglibc系を基本にします。

### 主な想定OS

- Ubuntu Server系
- Debian系
- Windows Server系
- 上記と互換性の高い一般的なLinuxサーバー

特定クラウド事業者専用にはしません。

AWS / Azure / Google Cloud / OCI / 国内VPS / 自宅サーバーなどでも、対応OSとアーキテクチャを満たせば同じサーバーバンドルを使える構造を目指します。

## 原則

プラットフォーム固有処理をゲームロジックへ混ぜません。

```text
Game / Domain
      ↓
Platform-neutral Application
      ↓
Adapters
      ↓
Windows / Android / Linux / Server
```

Windows版とAndroid版でゲームルールが変わる設計にはしません。
