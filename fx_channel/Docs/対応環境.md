# 対応環境

## ユーザー用アプリ

ユーザーアプリは **Flutter** で作ります。

| 形式 | OS | アーキテクチャ | 最低環境 |
|---|---|---|---|
| EXE | Windows | x64 | Windows 10以上 |
| APK | Android | arm64-v8a | Android 9.0 / API 28以上 |
| Web | ブラウザ | - | モダンブラウザ |

Windows版は `fx_channel_user.exe` が起動ファイルです。Flutter Windowsアプリは通常、EXE単体ではなくDLL/assetを伴うため、ReleaseではEXEを含むZIPとして配布します。

Android版はarm64向けAPKを正式成果物にします。

Web版は同じユーザーFlutterプロジェクトから生成し、任意でサーバーの `/play/` から公開できます。

## 運営用アプリ

ユーザー用とは別のFlutterプロジェクトです。

初期正式ターゲット：

- Windows x64
- Linux x64

Androidへ運営機能を入れることは標準方針にしません。

## サーバー

サーバーは **Python + FastAPI + Uvicorn** です。

正式配布はPython環境を要求せず、自己完結バンドルを用意します。

| 配布物 | 主な用途 |
|---|---|
| Linux x64 | Ubuntu Server / Debian / 一般的なx64 VPS |
| Linux arm64 | Ubuntu Server ARM64 / Debian ARM64 |
| Windows x64 | Windows Server / Windows上のセルフホスト |

## 原則

```text
Flutter User App
   ├─ Windows EXE
   ├─ Android APK
   └─ Web
        │
        ▼
   User API
        │
        ▼
Python / FastAPI Server
        ▲
        │
 Operator API
        │
Flutter Operator App
```

Windows/Android/Webでゲームルールは変えません。FX・ガチャ・スキル等のゲーム処理はサーバー側です。
