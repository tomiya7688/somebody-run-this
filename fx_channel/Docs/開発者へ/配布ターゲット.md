# 配布ターゲットとRelease要件

## User App — Flutter

必須成果物：

- Windows 10+ x64
  - 起動ファイル: `fx_channel_user.exe`
  - 配布: `fx-channel-user-windows-x64.zip`
- Android 9.0+ arm64-v8a
  - `fx-channel-user-android-arm64.apk`
- Web
  - `fx-channel-user-web.zip`
  - サーバーへ同梱する場合は `web-user/` に展開

Release gate：

- Windows x64でEXE起動
- Android arm64 / API 28でAPK起動
- Web buildが `/play/` で起動
- User APIへ接続
- Operator API/TokenをUser成果物へ含めない

## Operator App — Flutter

初期成果物：

- Windows x64
- Linux x64

User Appとは別ビルドです。

## Server — Python/FastAPI

必須成果物：

- Linux x64
- Linux arm64
- Windows x64

Release gate：

- 空ディレクトリへ展開
- example設定をコピー
- Token環境変数を設定
- Pythonを別途インストールせず起動
- `/health` 成功
- User API応答
- Operator APIが未認証アクセスを拒否
- 同梱Web版がある場合は `/play/` が表示

サーバーのPython/FastAPIは開発実装であり、運営者には自己完結バンドルとして渡します。
