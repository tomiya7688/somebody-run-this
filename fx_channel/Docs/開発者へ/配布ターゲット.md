# 配布ターゲットとRelease要件

正式Releaseは、ソースコードだけではなく利用者・運営者がそのまま使える成果物を作ります。

## User

必須ターゲット：

- Windows 10+ x64
- Android 9.0+ arm64-v8a

Release gate：

- Windows x64で起動確認
- Android arm64/API 28で起動確認
- User APIへ接続できる
- Operator API/Tokenを成果物へ含めていない

## Server

必須ターゲット：

- Linux x64
- Linux arm64
- Windows x64

Release gate：

- バンドルを空ディレクトリへ展開
- example設定をコピー
- Token環境変数だけ設定
- 追加ランタイムを手動導入せず起動
- `/health` が成功
- User APIが応答
- Operator APIが未認証アクセスを拒否

## Operator App

初期ターゲット：

- Windows x64
- Linux x64

## バンドル原則

Release成果物へPythonソースを置くだけ、という形式にはしません。

サーバーは自己完結実行形式にまとめ、運営者がPython環境を管理しなくてよい形を目標にします。

候補実装はPyInstaller等ですが、ビルドツール自体は交換可能にしておきます。

重要なのは成果物の契約です。

```text
extract
→ configure
→ start
```

この3段階で動くことをRelease gateにします。
