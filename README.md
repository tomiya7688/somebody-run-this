# somebody-run-this

> ## このリポジトリの中身は、好きに持っていってください
>
> **開発完了・開発途中・未完成・試作・発案段階を問いません。**
> このリポジトリに置かれているゲーム、コード、設計、仕様、アイデア、設定例、ドキュメントなどは、**「まだ完成していないから使ってはいけない」という扱いにはしません。**
>
> 使えそうなものがあれば、完成を待たずに持っていって構いません。
> コピー、フォーク、改造、別実装、開発の引き継ぎ、自分のサーバーでの運営、独自版の公開、収益化などに使ってください。
>
> **このプロジェクトの目的は「こちらで完成・運営すること」ではなく、誰かが拾って自由に続きをやれる状態で置いておくことです。**
>
> ただし、特定のファイル・素材・外部依存物などに個別のライセンスや利用条件が明記されている場合は、そちらの条件を優先してください。

作ったゲームを「誰か運営してくれ」という前提で置いていくプロジェクトです。

運営者は各ゲームの設定・利用条件に従って、自分の環境でサーバーを立てて運営できます。収益化方法や運営方針も、ゲームごとの条件の範囲内で運営者が決められる構成を目指します。

## Games

- [fx_channel](fx_channel/) — 現金を賭けず、仮想資産だけで遊ぶFXソーシャルゲーム

## 運営する人へ

各ゲームには、運営者向けの設定説明を用意します。
**まず各ゲームの `Docs/運営者へ/` を読んでください。**

ゲーム固有の設定値・外部API・シーズン設定など、運営時に変更すべき項目はそこへ集約します。

## 開発・セキュリティルール

開発時は [開発セキュリティ規約](.github/SECURITY_RULES.md) を必ず守ってください。

特に、C / C++ / Zig はプロジェクト管理下のソースコードでは全面禁止、PHPは当面禁止、JavaScriptの直書きは禁止してTypeScript / TSXを使用します。

また、ライブラリ・フレームワーク・ランタイム等を導入または更新する場合は、過去の知識やCVE一覧だけに頼らず、**その時点の最新セキュリティ情報を実際にインターネットで調査することを必須**とします。
