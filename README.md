# somebody-run-this

作ったゲームを「誰か運営してくれ」という前提で置いていくプロジェクトです。

運営者は各ゲームの設定・利用条件に従って、自分の環境でサーバーを立てて運営できます。収益化方法や運営方針も、ゲームごとの条件の範囲内で運営者が決められる構成を目指します。

## Games

- [fx_channel](fx_channel/) — 現金を賭けず、仮想資産だけで遊ぶFXソーシャルゲーム

## 運営する人へ

各ゲームには、運営者向けの設定説明を用意します。
**まず各ゲームの `Docs/運営者へ/` を読んでください。**

ゲーム固有の設定値・外部API・シーズン設定など、運営時に変更すべき項目はそこへ集約します。
