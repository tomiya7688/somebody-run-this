# somebody-run-this

作ったゲームを「誰か運営してくれ」という前提で置いていくプロジェクトです。

運営者は各ゲームの設定・利用条件に従って、自分の環境でサーバーを立てて運営できます。収益化方法や運営方針も、ゲームごとの条件の範囲内で運営者が決められる構成を目指します。

## Games

- [fx_channel](fx_channel/) — 現金を賭けず、仮想資産だけで遊ぶFXソーシャルゲーム

## 運営する人へ

各ゲームには、運営者向けの設定説明を用意します。
**まず各ゲームの `Docs/運営者へ/` を読んでください。**

ゲーム固有の設定値・外部API・シーズン設定など、運営時に変更すべき項目はそこへ集約します。

## 開発・セキュリティルール

開発時は以下を必ず守ってください。

- [開発セキュリティ規約](.github/SECURITY_RULES.md)
- [MISRA-inspired コーディング規約](.github/CODING_RULES.md)
- [Coding deviations](.github/CODING_DEVIATIONS.md)

特に、C / C++ / Zig はプロジェクト管理下のソースコードでは全面禁止、PHPは当面禁止、JavaScriptの直書きは禁止してTypeScript / TSXを使用します。

ライブラリ・フレームワーク・ランタイム・GitHub Action等を導入または更新する場合は、過去の知識やCVE一覧だけに頼らず、**その時点の最新セキュリティ情報を実際にインターネットで調査することを必須**とします。

このリポジトリはAIコーディングを前提としているため、AI生成コードを未検証コードとして扱い、静的解析・型検査・依存関係監査・秘密情報スキャン・CodeQL等をCIで実行します。
